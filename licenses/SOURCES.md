# Источники текстов лицензий

Сами условия лицензий сохранены на английском языке.

| Файл | Источник |
| --- | --- |
| `Zippy-MIT.txt` | Дословная копия `thirdparty/Zippy/LICENSE` |
| `miniz-MIT.txt` | Дословная копия `thirdparty/Zippy/Zippy/miniz/LICENSE` |
| `miniz-Unlicense.txt` | Блок Unlicense из `thirdparty/Zippy/Zippy/miniz/miniz.h`; удалено только оформление комментария |
| `nlohmann-json-MIT.txt` | [LICENSE.MIT версии 3.11.2](https://github.com/nlohmann/json/blob/v3.11.2/LICENSE.MIT) |
| `Hedley-MIT.txt` | Текст MIT из nlohmann/json 3.11.2 с авторским уведомлением Hedley, указанным в поставляемом `json.hpp` |
| `Hoehrmann-MIT.txt` | Тот же текст MIT с авторским уведомлением декодера UTF-8 из поставляемого `json.hpp` |
| `Grisu2-MIT.txt` | Тот же текст MIT с авторским уведомлением Grisu2 из поставляемого `json.hpp` |
| `Abseil-Apache-2.0.txt` | [LICENSE из той ревизии Abseil, на которую ссылается `json.hpp`](https://github.com/abseil/abseil-cpp/blob/10cb35e459f5ecca5b2ff107635da0bfa41011b4/LICENSE) |
| `Qt-LGPL-3.0.txt` | Текст из документации Qt 6.11.0, `qtdoc/lgpl.html`, после удаления только HTML-разметки |
| `Qt-GPL-3.0.txt` | Текст из документации Qt 6.11.0, `qtdoc/gpl.html`, после удаления только HTML-разметки; сохранено вводное предложение Qt |

Документация Qt: [LGPL](https://doc.qt.io/qt-6/lgpl.html) и
[GPL](https://doc.qt.io/qt-6/gpl.html). Это стандартные тексты лицензий,
а не изменение условий Qt или указание версии Qt, использованной при сборке
конкретного выпуска TSSLogViewer.
